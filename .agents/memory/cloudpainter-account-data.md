---
name: CloudPainter account data
description: The product expectation for where account-owned sketches and other data belong.
---

CloudPainter users expect their account and all of their data to be on the server.

**Why:** the user explicitly clarified this product expectation while requesting sketch recovery.

**How to apply:** make account-owned data server-backed, while preserving the current rule that a sketch is not copied to the account until the user explicitly chooses to back it up or associate it.
