---
name: Follow-up description limits
description: Runtime limit when proposing evidence-heavy verification follow-ups.
---

Keep each proposed follow-up description at or below 4,000 characters; retain
the complete evidence-heavy verification plan in a tracked project document
and include its execution requirements and identity in the proposal.

**Why:** The proposal callback rejects descriptions over 4,000 characters before
creating any tasks, even though its prose guidance does not state that limit.

**How to apply:** Measure description length before the one-shot proposal call.
Do not truncate safety boundaries, source identities or acceptance criteria;
shorten surrounding prose and reference the complete tracked plan instead.
